========================================
Redis 原始命令速查（常用运维）
========================================

一、Key 操作（通用）
========================================
KEYS *                    # 查看所有 key（生产慎用）
KEYS user:*               # 查看匹配的 key
EXISTS key                # 判断 key 是否存在
TYPE key                  # 查看 key 的类型
TTL key                   # 查看剩余过期时间（秒）
PTTL key                  # 查看剩余过期时间（毫秒）
EXPIRE key 3600           # 设置过期时间（秒）
PEXPIRE key 3600000       # 设置过期时间（毫秒）
PERSIST key               # 移除过期时间
RENAME old new            # 重命名 key
DEL key1 key2             # 删除 key（可多个）


二、清空数据库
========================================
FLUSHDB                   # 清空当前数据库
FLUSHALL                  # 清空所有数据库
DBSIZE                    # 查看当前数据库 key 数量


三、String
========================================
SET key value             # 存
GET key                   # 取
SETEX key 3600 value      # 存并设置过期时间（秒）
SETNX key value           # 不存在才存
INCR key                  # 自增 1
INCRBY key 10             # 自增指定值
DECR key                  # 自减 1


四、Hash
========================================
HSET key field value      # 存字段
HGET key field            # 取字段
HGETALL key               # 取所有字段
HDEL key field            # 删除字段
HEXISTS key field         # 判断字段是否存在
HLEN key                  # 字段数量


五、List
========================================
LPUSH key value           # 左边插入
RPUSH key value           # 右边插入
LPOP key                  # 左边弹出
RPOP key                  # 右边弹出
LRANGE key 0 -1           # 取所有
LLEN key                  # 列表长度


六、Set
========================================
SADD key member           # 添加
SMEMBERS key              # 取所有
SISMEMBER key member      # 判断是否存在
SREM key member           # 删除
SCARD key                 # 集合大小


七、ZSet
========================================
ZADD key score member     # 添加
ZRANGE key 0 -1           # 升序取所有
ZREVRANGE key 0 -1        # 降序取所有
ZREM key member           # 删除


八、查看服务器信息
========================================
INFO                      # 服务器信息
INFO memory               # 内存信息
INFO stats                # 统计信息
INFO keyspace             # 数据库统计
CONFIG GET *              # 查看所有配置
CONFIG GET maxmemory      # 查看内存限制
CLIENT LIST               # 查看客户端连接


九、调试（生产慎用）
========================================
MONITOR                   # 实时监控所有命令
SLOWLOG GET 10            # 查看慢查询日志
DEBUG OBJECT key          # 查看 key 内部信息


十、退出
========================================
QUIT                      # 退出 redis-cli
EXIT                      # 退出 redis-cli

========================================
Redis 数据库切换命令速查
========================================

一、切换数据库
========================================
SELECT 0        # 切换到 0 号数据库
SELECT 1        # 切换到 1 号数据库
SELECT 15       # 切换到 15 号数据库（最大 15）


二、查看当前数据库
========================================
SELECT 0        # 切换后不会显示当前是几号库
CLIENT INFO     # 查看当前客户端信息（包含 db 编号）

# 或者在 redis-cli 连接时显示
redis-cli -n 1  # 直接连接 1 号数据库


三、查看数据库信息
========================================
DBSIZE          # 当前数据库 key 数量
INFO keyspace   # 查看所有数据库的统计信息

# 输出示例：
# db0:keys=100,expires=10,avg_ttl=3600
# db1:keys=50,expires=5,avg_ttl=7200


四、清空数据库
========================================
FLUSHDB         # 清空当前数据库
FLUSHALL        # 清空所有数据库（慎用！）


五、连接时指定数据库
========================================
# redis-cli 方式
redis-cli -n 1                      # 连接 1 号数据库
redis-cli -h 127.0.0.1 -p 6379 -n 1 # 指定主机端口和数据库

# Go 代码方式
rdb := redis.NewClient(&redis.Options{
    Addr: "localhost:6379",
    DB:   1,  // 指定 1 号数据库
})


六、查看当前连接在哪个数据库
========================================
# redis-cli 中
CLIENT INFO | grep db

# 或者直接
INFO clients
