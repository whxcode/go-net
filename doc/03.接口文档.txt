========================================
Swaggo 注释速查表
========================================

一、通用注释（main.go）
========================================
// @title 项目名称
// @version 1.0
// @description 项目描述
// @host localhost:8080
// @BasePath /api
// @securityDefinitions.apikey ApiKeyAuth
// @in header
// @name token


二、接口注释（handler/controller）
========================================
// 函数名 接口描述
// @Summary 接口名称（简短）
// @Description 接口详细描述
// @Tags 分组标签
// @Accept json
// @Produce json
// @Success 200 {object} 返回类型 "成功"
// @Failure 400 {object} 返回类型 "参数错误"
// @Failure 500 {object} 返回类型 "服务器错误"
// @Router /path [method]
// @Security ApiKeyAuth


三、参数写法
========================================

1. Query 参数（GET /list?page=1&size=20）
----------------------------------------
// @Param page query int false "页码" default(1)
// @Param size query int false "每页数量" default(20)
// @Param keyword query string false "搜索关键词"
// @Param status query int false "状态" Enums(0,1,2)


2. Path 参数（GET /user/:id）
----------------------------------------
// @Param id path int true "用户ID"


3. JSON Body（POST /create）
----------------------------------------
// @Param request body model.CreateUserRequest true "创建用户请求"


4. FormData（POST /upload）
----------------------------------------
// @Param file formData file true "上传文件"
// @Param name formData string false "文件名称"


5. Header 参数
----------------------------------------
// @Param token header string true "认证token"


四、返回类型写法
========================================

1. 返回单个对象
// @Success 200 {object} model.UserInfoResponse "成功"

2. 返回数组
// @Success 200 {object} []model.UserInfoResponse "成功"

3. 返回 KResponse 包装
// @Success 200 {object} utils.KResponse{data=model.UserInfoResponse} "成功"

4. 返回 KResponse 数组包装
// @Success 200 {object} utils.KResponse{data=[]model.UserInfoResponse} "成功"

5. 返回 map（不推荐，无字段提示）
// @Success 200 {object} map[string]interface{} "成功"


五、常用结构体示例
========================================

// 请求结构体
type CreateUserRequest struct {
    Username string `json:"username" binding:"required"`
    Password string `json:"password" binding:"required"`
    Nickname string `json:"nickname"`
}

// 响应结构体
type UserInfoResponse struct {
    ID       uint   `json:"id"`
    Username string `json:"username"`
    Nickname string `json:"nickname"`
    Avatar   string `json:"avatar"`
}

七、生成命令
========================================

swag init --output ./docs             // 指定输出目录
